# Лендинг «Грант» — Yudaev School

Статический сайт без сборки и сервера (HTML + CSS + JS, шрифт Inter) — тот же подход и та же дизайн-система, что в `yudaev-landing-static`.
Открывается двойным щелчком по `index.html` (лучше Chrome или Edge последних версий).

Макет: [Figma, секция «Грант»](https://www.figma.com/design/edrQskKZyqRsAnQDu9XPQt/Untitled?node-id=27-4) — десктоп 1440 (`27:5`), мобильный 375 (`27:286`),
формы «Форма – Основная»: мобильная `27:566`, десктопная `27:686`.

## Страница

| Блок | Макет (десктоп / моб.) | Класс |
|---|---|---|
| Первый экран: сумма 11 000 000 ₽, карточки, кнопка | `27:6` / `27:287` | `.hero` |
| Фонд: остаток, табло, обратный отсчёт, «Получить грант» | `27:29` / `27:312` | `.fund` |

| Правила участия (5 пунктов) | `27:194` / `27:479` | `.rules` |
| Подвал: контакты, курсы, соцсети, лицензия | `27:227` / `27:508` | `.footer` |
| Поп-ап заявки (по кнопкам «Получить грант») | `27:686` / `27:566` | `#lead-modal` |

На десктопе фонд, шаги и заявка — одна белая карточка (`.sheet`), на мобильном — три отдельные.

## Структура

```
index.html
assets/css/fonts.css       @font-face Inter Web (вариативный, SIL OFL)
assets/css/tokens.css      токены: цвета, радиусы, отступы, шрифты, брейкпоинты       ← из static без изменений
assets/css/base.css        reset, типографика, фокус, sr-only, zoom ≥1921              ← из static без изменений
assets/css/components.css  .container, .section, .h2, .btn, .pill, .slider…            ← из static (без .try-card)
assets/css/forms.css       .field, .segmented, .consent, .lead-form                    ← из static (sections-social.css)
assets/css/grant.css       стили страницы (все блоки), значения из Figma
assets/css/lead-modal.css  поп-ап заявки (<dialog>)
assets/css/motion.css      анимации — подключается последним
assets/js/fund.js          остаток фонда: логика, табло, подпись «Осталось N грантов»
assets/js/countdown.js     обратный отсчёт «До окончания акции»
assets/js/lead-modal.js    поп-ап и форма на странице: проверка полей, экран «отправлено»
assets/js/main.js          появление блоков (data-rv) и слов заголовков (.h2)
assets/img/…               картинки из Figma (WebP), иконки и логотипы (SVG)
```

Порядок подключения CSS: `fonts → tokens → base → components → forms → grant → lead-modal → motion`. Скрипты — `defer`, в конце `<body>`.

## Дизайн-система (как устроено в yudaev-landing-static)

**Брейкпоинты** — mobile-first, значения повторены в каждом `@media`:

| Имя | Ширина | Что это |
|---|---|---|
| base | < 768 | мобильный макет (кадр 375) |
| md | 768–1199 | мобильная раскладка в карточке до 720 px; три шага в ряд |
| lg | ≥ 1200 | десктоп (кадр 1440): первый экран — на весь экран (см. ниже), остальное — контейнер 1312 |
| ≥ 1921 | | вся страница `zoom: 1.2` (`base.css`) |

**Первый экран на весь экран (только десктоп ≥ 1200):** высота блока равна высоте окна, но не меньше 560 px. На мобильном и планшете высота по макету (375×649), не растягивается. Композиция 1440×800 вписывается в окно:
`--u = min(ширина/1440, высота/800)`, всё внутри считается от `--u`. Заголовок, плашка, логотип и сумма привязаны к верху, карточки, текст и кнопка — к низу,
поэтому если окно «выше» макета, лишнее место появляется между заголовком и текстом, а если «шире» — по бокам остаётся фон. Выше 1920 учитывается `zoom: 1.2` у body (`--zoom`).

**Единая сетка (десктоп ≥ 1200).** Контейнер — `max(64px, (100% − var(--grid-max)) / 2)` с каждой стороны, `--grid-max: 1520px` (в начале `grant.css`): до 1440 поля 64 px, шире 1440 контент растёт до 1520 px и остаётся по центру. Чтобы сделать сетку у́же или шире — поменять одно число `--grid-max` (макетные размеры для 1440 при этом не меняются).
Ровно по этим краям стоят все блоки: логотип, подпись, заголовок, текст и кнопка первого экрана, крупная сумма (контур первой «1» и «₽» — на краях контейнера), фонд, шаги, заявка, правила, подвал.
Правая «половина» везде начинается на одной линии — `50% + 5px` от левого края контейнера (на 1440 это x = 725): подпись фонда, правая панель с персонажем, форма заявки, правая колонка правил, курсы и контакты в подвале.
Между плашкой с остатком и формой заявки — 40 px. Первый экран следует за контейнером: крупная сумма идёт от края до края, карточки с персонажем растут пропорционально, заголовок и плашка опускаются, если сумма крупнее макетной; высоты блоков «Фонд» и «Как получить» растут вместе с шириной, чтобы картинки не растягивались. Мобильный: карточки на 8 px от края, тексты на 20 px.

**Токены:** тёмный `#0C0A1F`, поверхность `#EAEDF1`, радиусы 16/24/32/40/48/64, радиус секции 36 (моб.) / 64 (десктоп), сетка отступов 4 px.
Шрифт — Inter 500 везде (в макете HelveticaNeueCyr, замена как на всём сайте), межбуквенный −2…−4 % по макету.

**Отличия от общих токенов:** зелёный в макете «Грант» — `#CFFF32`, на сайте — `#CAFF01`. В `grant.css` (первые строки) переопределены `--color-lime` и
`--page-inset: 0`. Вернуть зелёный сайта — убрать эти строки и заменить `rgba(207, 255, 50, …)` в `motion.css` на `rgba(202, 255, 1, …)`.

**Анимации** (`motion.css`): всё внутри `prefers-reduced-motion: no-preference`; анимируются `opacity` / `translate` / `scale` (+ `blur` для мягкого появления).
Появление блоков — атрибут `data-rv`; заголовки `.h2` — слова выезжают по одному; первый экран — каскад при загрузке, карточки парят;
кнопки `.btn` пульсируют; цифры табло при смене «опускаются»; полоса остатка плавно сдвигается; точка LIVE «дышит»; шаги и соцсети приподнимаются при наведении.

## Остаток фонда (`fund.js`)

Разметка: `[data-fund-sum]` — сумма («10 600 000 ₽»), `[data-fund-flip]` — табло (цифры собирает скрипт), `[data-fund-grants-text]` — «Осталось N грантов по 200 000 ₽»
(с правильным склонением), `[data-fund-bar]` — полоса (`--p` 0…1).

* Первый заход: стартовое значение случайное, кратное гранту, 10,2 / 10,4 / 10,6 / 10,8 млн ₽.
* Шаг всегда −200 000 ₽ (один грант — число грантов остаётся целым). Интервал зависит от того, сколько уже ушло, и случайный (±17 %):

  | Фаза | Условие | Интервал |
  |---|---|---|
  | быстрая | ушло меньше 1 000 000 ₽ от старта (ровно 5 шагов) | ~30 с |
  | средняя | остаток больше 6 000 000 ₽ | ~5 мин |
  | медленная | 6 000 000 ₽ и ниже | ~30 мин |

* **Минимум — 9 800 000 ₽** (ниже не падает, константа `floor`). Поэтому от старта 10,2–10,8 млн до пола остаётся 2–5 шагов (1–2,5 минуты);
  «средняя» и «медленная» фазы при таком поле не наступают. Они остаются в коде и заработают, если пол опустить.
* Состояние `{start, left, nextAt}` — в `localStorage` (`ys-grant-fund-v1`). Перезагрузка внутри интервала не сбрасывает таймер.
  Если шаг «должен был» случиться, пока посетителя не было, он произойдёт через 3–8 с после открытия — без «догонялки».
  Вкладка в фоне шаги откладывает. Вторая вкладка подхватывает изменения через событие `storage`.
* Проверка: в консоли `YSFund.reset()` и перезагрузить — новое стартовое значение; `YSFund.state()` — текущее.
* Константы и интервалы — `CONFIG` в начале `fund.js`.

## Что настроить

* **Куда уходит заявка:** место помечено `TODO: отправка` в `assets/js/lead-modal.js` (отправьте `FormData`, например `fetch('/api/lead', …)`).
  Пока заявки никуда не уходят: показывается экран «Заявка отправлена».
* **Конец акции:** `data-countdown="2026-11-11T23:59:59+03:00"` у блока `.countdown` (по Москве, 11 ноября включительно). После окончания показывает нули.
* **Документы (подставлены):** лицензия (миниатюра и текст в подвале) — `yudaevschool.ru/wp-content/uploads/2025/09/license.pdf`; в согласии «персональных данных» — согласие на обработку ПД (pdf),
  «политику конфиденциальности» — `yudaevschool.ru/privacy`; в подвале под юридическим текстом — публичная оферта `yudaevschool24.online/oferta`, политика конфиденциальности и политика обработки ПД (pdf).
  Строки с документами в подвале в Figma нет — она добавлена; убрать: блок `<ul class="footer__docs">` в `index.html`.
* **Адрес страницы:** `https://yudaevschool24.online/grant2` — прописан в `canonical` и `og:url`; якорь `#zayavka` — блок заявки (`id="zayavka"`).
* **Ссылки подвала без адресов** (соцсети, курсы, Telegram) — заглушки `href="#"` с `aria-disabled="true"`: выглядят как текст и не кликаются. Подставьте адреса и уберите `aria-disabled`.
  Телефон и почта — рабочие ссылки.
* **Индексация закрыта** (`noindex` в `<head>`). Перед публикацией уберите.
* **Согласие на обработку данных** по умолчанию не отмечено (в макете галочка нарисована отмеченной). Это сделано намеренно: предзаполненное согласие юридически не считается согласием.

## Известные расхождения с макетом

* Стартовый остаток — 10,2–10,8 млн ₽ (по ТЗ), в макете нарисовано 9 800 000 ₽, а подпись «Осталось 27 грантов» в макете не сходится с суммой (9,8 млн = 49 грантов).
  В вёрстке подпись считается из суммы. Полоса остатка тоже показывает реальную долю, а не нарисованные ~75 %.
* Табло занимает всю ширину панели (ряд цифр заканчивается вровень с полосой остатка): ячейки делят ширину поровну, поэтому на 8-значных суммах (от 10 млн) они чуть уже, чем на 7-значных в макете.
* Крупная сумма на первом экране набрана Inter (он шире HelveticaNeueCyr): размер и трекинг подогнаны так, чтобы ширина совпала с макетом.
* В макете «Онлайн-школа профессионального дизайн образования» (без дефиса) — текст сохранён как есть.
* Широких кадров (1920, 2440) в макете нет: выше 1440 композиция остаётся «макетом 1440» по центру.
* Из картинок Figma не использованы слои, полностью перекрытые верхними (например, нижние подложки первого экрана) — на вид это ничего не меняет.
